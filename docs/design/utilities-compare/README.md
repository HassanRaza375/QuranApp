## Differences from the prototype (deliberate)

| Prototype | Revamp | Why |
| --- | --- | --- |
| Tasbeeh: five dhikr and a custom one typed by us | The legacy presets (generated from the legacy file) | No typed religious text |
| Tasbeeh: "After prayer" mode with the Sunni and Ja'fari Tasbih of Fatima orders | Not present | No legacy data and no reviewed source |
| Tasbeeh: goals 33, 99, 100 and an infinity goal; a custom dhikr name | 33, 99, 100 only; the custom counter has no name | Legacy parity |
| Tasbeeh: an inline "Reset this count?" confirmation | Reset with a toast and Undo | Undo over confirm |
| Tasbeeh: no vibration control | A "Vibrate on count" switch, shown only where supported; off with Reduce motion | Approved decision 8 |
| Sajda: typed list, references, Arabic, "Obligatory / Not obligatory" chips, the Hanafi chip, per-tradition paragraphs | The service's 15 references, the reader's Arabic, juz and page from the data, no obligation statements | Rulings need a reviewed source |
| Sajda: "4 obligatory verses" summary and "Hanafi count is 14" | "15 verses, as listed by this app’s data." | Same |
| Asma: 99 names typed from memory | The legacy 99 names (Arabic, Urdu, transliteration, meaning) | Legacy data |
| Asma: a "Saved" chip, a name sheet with "Count this name" | Same, plus Play shown disabled until the player | Phase 4B |
| (legacy only) a YouTube embed and near-invisible English text | Neither | A third-party page; contrast |
