# Per page: prototype and revamp compared (Phase 9A)

Generated by `scripts/screenshots/phase-09a-per-page.mjs` on the production build. The revamp images show **real Qur'an text** fetched from the same source the app uses (`quranapi.pages.dev`), not synthetic text; nothing but the images is stored.

- Four pair images: `desktop|mobile-light|dark-page.jpg` (prototype page 1 on the left, revamp page 1 on the right; page 1 is the only page the prototype has text for).
- Twelve states, each at desktop light and mobile dark: `state-<name>-<device>-<theme>.jpg`.

Looked at by me: the desktop light pair, the two-surahs state at desktop light and the largest-scale two-surahs state at mobile dark. The other images were generated and not individually inspected.

## Differences from the prototype (deliberate)

| Prototype | Revamp | Why |
| --- | --- | --- |
| Text for page 1 only; "appears here, from your Qur'an data" on the rest | Every one of the 604 pages, from the generated page starts and the surah reader's cached text | Real data; each page checked against the service's own page answer |
| Four justified lines (looks like mushaf lines) | Flowing justified text, with a plain note: "…It is not a line-for-line copy of the printed page." | There is no line data; the page does not pretend |
| Page-to-surah, page-to-juz mapping and demo page 49 | The generated page starts and juz starts | Typed mapping and the "20 pages per juz" rule are placeholders |
| One surah name in the head | Every surah on the page ("Al-Baqara, Aal-i-Imraan"); "Juz 4 and 5" when a juz begins mid-page | A page can hold two surahs; nothing is picked |
| Surah banner and Bismillah only on page 1 | The banner and the Bismillah wherever a surah starts (surahs 2 to 114 except 9; read from surah 1's data) | The surah reader's rule; no typed text |
| A−/A+ with no stated effect | A−/A+ write the global Arabic size (and show it, "1.0×"); the Settings slider moves with them | One setting |
| Pin page, Play page | Pin page (Page slot of `quran:pins:v1`) and Save (`page:N`), both with Undo; Play page visible, `aria-disabled`, "Coming with the player" | Play waits for Phase 4B |
| Slider, Go to page, small Previous/Next arrows | Previous and Next with text, a labelled slider, Go to page with a visible error | Accessibility and 44px targets |
| Mini player strip visible | Not shown (no audio on this page yet) | |

## States

mid-surah (page 3), surah-start (page 2: banner and Bismillah), two-surahs (the first page where one surah ends and the next begins), last-page (604: several short surahs), largest-scale and largest-scale-two-surahs (Arabic size 1.6), loading (skeleton), not-saved-offline ("Connect once to read it."), load-failed, bad-go-to (700), invalid-address (`?page=700` shows page 1 with a notice), pinned-and-saved.
