# Phase 17 — Account, sign in and avatar: design screens

Light screens are in this folder; dark versions are in `dark/`. PNGs are 2x.
These are mockups for the Night Study design system (Instrument Sans, Newsreader).
The names, email and sample counts are placeholders.

1. 01-settings-account-signed-out: Settings, Account section, signed out
2. 02-sign-in: Sign in (Google, email and password)
3. 03-create-account: Create account
4. 04-choose-what-to-sync: first sign-in; Library, Progress and Settings switches (all off until the user turns them on)
5. 05-account-signed-in: Account page with sync status, switches, sign out, delete account, merge-undo toast
6. 06-profile-photo-crop: profile photo sheet (circular crop, zoom, remove)
7. 07-desktop-account-menu: desktop shell with the header account menu open

Default avatar: pointed-arch outline with the user's initial (geometric, no silhouette).
Alternatives were an eight-point star and a plain solid circle with the initial.
The Google "G" is a plain letter here; the build uses Google's official logo asset.
All wording is new and goes into CONTENT_TO_VERIFY.md.
